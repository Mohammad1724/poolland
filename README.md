## چرا پول‌لند؟

اگر VPN می‌فروشی، حتماً این‌ها برایت آشناست:

- «فلانی ۵۰۰ هزار بدهکاره، دو ماهه نمی‌ده…» 🙄
- «کی سرویسش تموم می‌شه؟ یادم رفت تمدید کنم.»
- «این ماه چقدر فروختم؟ چقدر خرج سرور و تبلیغات شد؟ اصلاً سود کردم یا نه؟»
- «مشتری خارجی با تتر حساب می‌کنه، چطور با فروش تومانی قاطی نشه؟»

پول‌لند دقیقاً برای همین‌ها ساخته شده — یک دفتر ساده که **مخصوص کار تو** طراحی شده، نه یک نرم‌افزار حسابداری پیچیده.

## ✨ قابلیت‌ها

### 👥 مدیریت مشتری‌ها و حساب‌ها
- ثبت مشتری با نام، شماره تماس، آیدی تلگرام و یادداشت
- **بدهکار / بستانکار** هر مشتری، همیشه جلوی چشم
- ثبت **بدهی یا طلب قبلی** برای شروع از وضعیت فعلی
- فیلتر سریع «بدهکاران» و «بستانکاران» + جست‌وجو
- دکمه‌ی تماس، تلگرام و کپی خلاصه‌ی حساب
- **صورت‌حساب PDF** برای هر مشتری، آماده‌ی ارسال

### 🔑 اشتراک‌ها و تاریخ انقضا
- ثبت فروش اشتراک با تاریخ شروع و پایان (تقویم **شمسی**)
- پلن‌های آماده: «۱ ماهه ۵۰ گیگ»، «۳ ماهه نامحدود» و…
- هشدار خودکار **سرویس‌های نزدیک انقضا** و منقضی‌شده
- تمدید **یک‌کلیکی**: اشتراک جدید از فردای تاریخ پایان ساخته می‌شود
- نوار پیشرفت عمر سرویس و تعداد روزهای باقی‌مانده

### 📒 دفترها: شخصی و کسب‌وکار
- هر تراکنش به یک **دفتر** تعلق دارد — پیش‌فرض: «کسب‌وکار» و «شخصی»
- **سوییچر دفتر** در نوار بالای برنامه: با یک ضربه، کل داشبورد، نمودارها، گزارش‌ها و خروجی PDF/CSV فقط برای همان دفتر نمایش داده می‌شود
- **کارت مقایسه‌ی دفترها** در داشبورد: درآمد، هزینه و سود کسب‌وکار و شخصی کنار هم — برای اینکه بفهمی واقعاً چقدر درآمد داشته‌ای
- مشتری، اشتراک و هشدار انقضا فقط در دفتر کسب‌وکار نمایش داده می‌شوند
- ساخت دفتر دلخواه با نام و رنگ خودت در **تنظیمات ← دفترها**
- داده‌های قدیمی (که فیلد دفتر ندارند) خودکار در دفتر کسب‌وکار حساب می‌شوند

### 💵 حسابداری و سود واقعی
- چهار نوع تراکنش: **درآمد**، **هزینه**، **دریافت از مشتری**، **پرداخت به مشتری**
- ثبت **نسیه یا نقدی** برای هر فروش/هزینه
- دسته‌بندی درآمد و هزینه (خرید سرور، دامنه، تبلیغات، اجاره، خوراک، حقوق، …) و امکان ساخت دسته‌ی دلخواه
- گزارش **سود = درآمد − هزینه − برگشت وجه**
- **موجودی صندوق** (نقد + بانک) با جریان نقدی واقعی
- تراکنش‌های دوره‌ای برای ترکیدن سرور یا هزینه‌های اشتباه

### 💱 چند ارزی
- تومان (پایه) + دلار، تتر، یورو و **هر ارزی که خودت اضافه کنی**
- هر تراکنش **نرخ تبدیل خودش** را ذخیره می‌کند (اسنپ‌شات)، پس گزارش‌های قدیمی با تغییر قیمت دلار خراب نمی‌شوند
- نمایش بدهی هر مشتری **به تفکیک ارز** (مثلاً ۲۰ دلار بدهکار + ۵۰۰ هزار تومان)

### 📊 گزارش‌ها و خروجی
- نمودار درآمد/هزینه‌ی ۶ ماه اخیر
- نمودار دایره‌ای هزینه‌ها به تفکیک دسته
- برترین مشتری‌ها و منابع درآمد
- بازه‌های آماده: این ماه، ماه قبل، ۳ ماه، ۶ ماه، امسال، همه
- خروجی **PDF** گزارش دوره (با جدول سود هر دفتر)، و **CSV (اکسل)** تراکنش‌ها و مشتری‌ها — هر دو هماهنگ با فیلتر دفتر

### 🔒 حریم خصوصی و پشتیبان
- **۱۰۰٪ آفلاین** — بدون حساب کاربری، بدون سرور، بدون اینترنت
- همه‌ی داده‌ها فقط روی دستگاه خودت (Hive، بدون نیاز به SQLite)
- **پشتیبان‌گیری JSON** و ارسال با تلگرام/واتس‌اپ/ایمیل یا ذخیره در گوشی
- **بازگردانی** با انتخاب فایل پشتیبان
- حالت تاریک / روشن / سیستم + اعداد فارسی
- برنامه‌ی **حسابداری کاملاً فارسی و راست‌به‌چپ** با تقویم شمسی

## نصب و اجرا

### ۱) نسخه‌ی آماده‌ی اندروید (APK)
آخرین نسخه را از صفحه‌ی **[Releases](../../releases/latest)** دانلود کن:

| فایل | مناسب برای |
|---|---|
| `poolland-vX.X.X-arm64-v8a.apk` | **۹۵٪ گوشی‌های امروزی** (سبک‌ترین و پیشنهادی) |
| `poolland-vX.X.X-armeabi-v7a.apk` | گوشی‌های قدیمی‌تر ۳۲بیتی |
| `poolland-vX.X.X-universal.apk` | همه‌ی گوشی‌ها (حجم بیشتر) |

> روی گوشی، نصب از منابع نامعتبر (Install unknown apps) را برای مرورگر یا فایل‌منیجر فعال کن.
> هر بار تگ جدید (`v1.x.x`) بزنی، GitHub Actions خودش APK می‌سازد و در Releases می‌گذارد.

### ۲) ساخت از سورس
```bash
# پیش‌نیاز: Flutter 3.4x به بالا
git clone https://github.com/Mohammad1724/poolland.git
cd poolland
flutter pub get
flutter run                    # اجرا روی گوشی/شبیه‌ساز
flutter build apk --release    # ساخت فایل APK
```

### ۳) نسخه‌ی وب (قابل نصب روی گوشی مثل اپ)
نسخه‌ی وب به‌صورت خودکار روی شاخه‌ی `gh-pages` ساخته و به‌روز می‌شود.
برای فعال‌سازی یک‌باره: **Settings → Pages → Source: «Deploy from a branch» → Branch: `gh-pages` / root → Save**

آدرس نهایی: `https://mohammad1724.github.io/poolland/`

> بیلد وب با `--no-web-resources-cdn` ساخته می‌شود؛ یعنی هیچ فایلی از CDN گوگل (gstatic) بارگذاری نمی‌شود
> و روی اینترنت ایران بدون مشکل باز می‌شود.

## شروع سریع

۱. در اولین اجرا، نام کسب‌وکار و **موجودی اولیه صندوق** را وارد کن
۲. مشتری‌ها را اضافه کن (بدهی قبلی هر کس را هم می‌توانی وارد کنی)
۳. پلن‌های فروشت را در «تنظیمات ← پلن‌های فروش» بساز
۴. از دکمه‌ی ➕ هر فروش را ثبت کن؛ بقیه‌ی حساب‌ها خودکار به‌روز می‌شوند
۵. برای امتحان سریع، در خوش‌آمدگویی گزینه‌ی **«اول با داده‌ی نمونه امتحان کنم»** را بزن

> می‌خواهی ببینی چطور کار می‌کند؟ همین حالا با داده‌ی نمونه امتحان کن، بعد از «تنظیمات ← پاک کردن همه‌ی داده‌ها» از صفر شروع کن.

## منطق حسابداری (قرارداد علامت‌ها)

| وضعیت | معنی |
|---|---|
| مانده **مثبت** | مشتری **به تو بدهکار** است |
| مانده **منفی** | **تو به مشتری بدهکار**ی (پیش‌پرداخت یا برگشت وجه) |
| تراکنش **نقدی** | روی صندوق اثر دارد |
| تراکنش **نسیه** | روی حساب مشتری اثر دارد |

- **سود** = درآمد − هزینه − برگشت وجه
- **موجودی صندوق** = موجودی اولیه + فروش‌های نقدی + وصولی‌ها − هزینه‌های نقدی − پرداخت‌ها
- اگر مشتری چیزی بخرد و پولی ندهد، کل مبلغ به‌عنوان «درآمد» ثبت می‌شود و همان مقدار به بدهی او اضافه می‌شود.

## ساختار پروژه

```
lib/
├── core/            # ابزارها: قالب‌بندی اعداد و تاریخ شمسی، ارز، پشتیبان‌گیری
├── data/            # مدل‌ها، منطق حسابداری، دیتابیس (Hive)، گزارش PDF
│   ├── models.dart      # Customer, Subscription, Plan, Txn, Category, Settings
│   ├── ledger.dart      # محاسبات خالص: مانده، سود، سری ماهانه، وضعیت اشتراک
│   ├── repository.dart  # عملیات برنامه (فروش، تمدید، دریافت، …)
│   └── pdf_service.dart # گزارش و صورت‌حساب PDF با فونت فارسی
└── ui/              # رابط کاربری
    ├── dashboard_page.dart      # داشبورد خلاصه
    ├── customers_page.dart      # فهرست و پروفایل مشتری
    ├── subscriptions_page.dart  # اشتراک‌ها و انقضا
    ├── transactions_page.dart   # دفتر تراکنش‌ها
    ├── reports_page.dart        # گزارش‌ها و خروجی‌ها
    ├── settings_page.dart       # تنظیمات، ارزها، دسته‌ها، پشتیبان
    ├── forms/                   # فرم‌های ثبت
    └── widgets/                 # ویجت‌های مشترک و نمودارها
```

**نکته‌ی معماری:** همه‌ی محاسبات حسابداری در `ledger.dart` به‌صورت **تابع خالص** نوشته شده‌اند؛
یعنی بدون رابط کاربری و بدون دیتابیس قابل تست هستند (به همین دلیل تست‌های دقیقی داریم).

### کمک می‌خواهم در:
- ذخیره‌سازی ابری / همگام‌سازی بین دو گوشی
- اعلان (Notification) واقعی برای سرسید انقضا
- نمودار پول‌لند و سرور (هزینه‌ی هر سرور در برابر فروشش)
- ساخت رمز/قفل ورود
- ویجت صفحه‌ی اصلی اندروید
- ترجمه به انگلیسی

اگر ایده یا باگی داری، [Issue](../../issues) بزن یا PR بفرست. خوشحال می‌شوم. 🙂
هیچ وابستگی به سرویس خارجی نداریم و همه‌چیز در یک اپ آفلاین جمع است.

## حریم خصوصی

پول‌لند **هیچ داده‌ای را جایی نمی‌فرستد**. نه آنالیتیکس دارد، نه تبلیغات، نه سرور.
همه‌ی اطلاعات در دیتابیس محلی روی گوشی خودت ذخیره می‌شود و با فایل پشتیبان JSON می‌توانی آن را منتقل کنی.
